# 04 - 图形桌面（XFCE4 + VNC）

在手机上跑一个完整的 Linux 图形桌面，从电脑远程访问。

## 4.1 为什么选 VNC 而不是 Termux:X11

| 方案 | 能否从电脑访问 | 说明 |
|------|--------------|------|
| **Termux:X11** | ❌ 不能 | 只能在手机本机屏幕上显示 |
| **VNC** | ✅ 能 | 网络传输画面，任何设备可连 |
| XRDP / RDP | ✅ 能 | 但 Termux 侧配置更复杂 |

**结论**：需求是"在电脑上看手机桌面"，所以选 VNC。

---

## 4.2 安装

```bash
# 1. 加 X11 软件源（图形组件不在主源里）
pkg install -y x11-repo
pkg update

# 2. 装 XFCE 桌面 + TigerVNC + 音频
pkg install -y xfce4 tigervnc dbus pulseaudio
```

> 这一步包很多（几百 MB），建议在 WiFi 下做，且确保已换清华源。

---

## 4.3 设置 VNC 密码

```bash
mkdir -p ~/.vnc
vncpasswd
```

- 输入两次密码（本文档用的是 `<VNC_PASSWORD>`）
- 问 "Would you like to enter a view-only password" 时输 `n`

**密码文件位置**：
- 手机：`~/.vnc/passwd`
- 电脑：`C:\Users\<用户名>\.vnc\passwd`

### ⚠️ 坑：不要自己生成密码文件

VNC 密码文件格式是 **8 字节 DES 加密**。在 Windows 上想生成一份会遇到一连串问题：

- `vncviewer.exe` **没有** `-storepasswd` 选项（Linux 版才有）
- OpenSSL 3 **默认禁用了 DES**，`openssl enc -des-ecb` 直接报错
- 自己用 Python 实现 DES 容易算错（我就踩了这个坑，算出来的文件认证失败）

**正确做法**：直接从手机复制。

```bash
ssh nubia 'base64 -w0 ~/.vnc/passwd' | base64 -d > ~/.vnc/passwd
```

> 用 base64 中转是为了避免二进制内容在传输中被修改。

## 4.4 配置桌面启动

### `~/.vnc/xstartup`

让 VNC 启动时拉起 XFCE 桌面：

```bash
#!/data/data/com.termux/files/usr/bin/bash
unset SESSION_MANAGER
unset DBUS_SESSION_BUS_ADDRESS

# 启动音频服务
pulseaudio --start --exit-idle-time=-1 2>/dev/null

# 启动 XFCE 桌面
exec startxfce4
```

```bash
chmod +x ~/.vnc/xstartup
```

> `unset SESSION_MANAGER` 和 `unset DBUS_SESSION_BUS_ADDRESS` 是必要的——否则 XFCE 可能启动失败或卡住。

### `~/.vnc/tigervnc.conf`

```conf
$session="xfce-session";
$geometry="1920x1080";
$depth="24";
$localhost="no";
```

| 参数 | 说明 |
|------|------|
| `$geometry` | 分辨率，可按需改 |
| `$depth` | 色深，24 位真彩 |
| `$localhost="no"` | **关键**：监听所有网卡，否则只有手机本机能连 |

> ⚠️ `$localhost="no"` 有时不生效，仍需在启动命令里显式加 `-localhost no`。

## 4.5 启动/停止脚本

### `~/start-vnc.sh`

```bash
#!/data/data/com.termux/files/usr/bin/bash
export DISPLAY=:1
termux-wake-lock

# 清理旧会话
vncserver -kill :1 >/dev/null 2>&1
pkill -f Xtigervnc 2>/dev/null
sleep 1

# 启动
vncserver :1 -geometry 1920x1080 -depth 24 -localhost no 2>&1 | tail -5
sleep 2

if pgrep -f "Xvnc :1" >/dev/null; then
    echo "✅ VNC 已启动: <手机IP>:5901"
else
    echo "❌ 启动失败，日志:"
    tail -20 ~/.vnc/*:1.log 2>/dev/null
fi
```

### `~/stop-vnc.sh`

```bash
#!/data/data/com.termux/files/usr/bin/bash
vncserver -kill :1 2>/dev/null
pkill -f Xtigervnc 2>/dev/null
termux-wake-unlock 2>/dev/null
echo "✅ VNC 已停止"
```

```bash
chmod +x ~/start-vnc.sh ~/stop-vnc.sh
```

## 4.6 从电脑连接

```bash
# 命令行
"C:\Program Files\TigerVNC\vncviewer.exe" -passwd "%USERPROFILE%\.vnc\passwd" <PHONE_IP>:5901
```

或打开 TigerVNC Viewer 图形界面，地址填 `<PHONE_IP>:5901`，输密码。

### 连接成功的日志特征

```
CConn: Connected to host <PHONE_IP> port 5901
CConnection: Server supports RFB protocol version 3.8
CConnection: Choosing security type VncAuth(2)
CConnection: Enabling continuous updates          ← 认证通过，开始传画面
DesktopWindow: Reducing window size to fit on current monitor
```

### 首次连接较慢

XFCE 首次启动要初始化配置，等 10-20 秒。之后会快很多。

## 4.7 在图形界面里装软件

桌面跑起来后，可以在里面装 GUI 程序：

```bash
# 浏览器（Firefox，Termux 官方重编译版）
pkg install -y firefox

# 文件管理器
pkg install -y pcmanfm

# 终端
pkg install -y xfce4-terminal
```

> **⚠️ 关于 Edge / Chrome**：这两个**装不了**。原因见下节。

### 为什么不能装 Microsoft Edge / Google Chrome

这不是配置问题，是**架构层面的限制**：

| 障碍 | 说明 |
|------|------|
| **libc 不同** | Edge/Chrome 官方只发 glibc 版本；Termux 用的是 Android 的 Bionic libc |
| **动态链接器路径** | glibc 程序要 `/lib/ld-linux-aarch64.so.1`，Android 只有 `/system/bin/linker64` |
| **非 PIE 编译** | Android 5.0+ 强制要求 PIE 可执行文件，官方二进制不满足 |

即使 AppImage 或 `.deb` 也不行——AppImage 只是把 glibc 环境一起打包，仍然跑在 Bionic 上。

**替代方案**：
- **Firefox**：Termux 官方为 Bionic 重编译，`pkg install firefox` 即可 ✅
- **Chromium**：同样有 Termux 移植版 ✅
- 真要 Edge：只能用 `proot-distro` 跑完整 glibc 发行版（性能损失大）

## 4.8 其他访问方式

### 手机本机访问（不需要电脑）

用 VNC 客户端 App 连 `127.0.0.1:5901`：
- Android: bVNC、MultiVNC、AVNC
- 这样手机自己也能用这个桌面

### 通过 SSH 端口转发

如果不想暴露 5901 端口：

```bash
ssh -L 5901:127.0.0.1:5901 nubia
# 然后本机 vncviewer 127.0.0.1:5901
```

## 4.9 故障排查

### VNC 连不上

```bash
# 检查 Xvnc 进程
ssh nubia 'pgrep -af Xvnc'

# 不在就重启
ssh nubia '~/start-vnc.sh'

# 看日志
ssh nubia 'tail -30 ~/.vnc/*:1.log'
```

### "Bad obfuscated password length"

密码文件损坏或格式错误。从手机重新复制（见 4.3 节）。

### "Authentication failed"

密码文件与服务器不匹配。同样从手机重新复制。

### 黑屏 / 只有灰底

`~/.vnc/xstartup` 没配好或没有执行权限。

```bash
ssh nubia 'ls -la ~/.vnc/xstartup'   # 应有 x 权限
ssh nubia 'cat ~/.vnc/xstartup'
```

### 桌面卡顿

VNC 传输全画面，网络差时明显。可以：
- 降低分辨率（改 `start-vnc.sh` 里的 `-geometry`）
- 降低色深到 `-depth 16`
- 确认走的是 Tailscale 直连而非中继
