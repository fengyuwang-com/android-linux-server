## 1.2 为什么必须装 Termux:API

这是本方案里**最容易被忽略、但缺了就不成立**的一环。

Termux 本身只是个终端模拟器，运行在 Android 应用沙箱里，**没有权限直接访问手机硬件**。

`Termux:API` 是一个独立的 APK，充当"中间人"，通过 Android Intent 机制把命令转发给系统 API：

```
Termux 命令行  →  termux-media-player play xxx
      ↓  （Android Intent 通信）
Termux:API APK  →  实际调用 Android MediaPlayer
      ↓
手机真的开始播放音频
```

### 没有它会怎样

`termux-notification`、`termux-media-player`、`termux-wake-lock`、`termux-clipboard-get` 等命令**全部无效**——命令存在（因为 `termux-api` 包装了），但调用时卡住或静默失败。

### 在本方案里的关键作用

Termux:API 承担了一个**决定性角色**：靠它循环播放静音音频，骗过 Android 的省电冻结机制，让手机息屏后 Termux 不被冻结。

没有 Termux:API，第 5 章的息屏保活方案**无法实现**。

## 1.3 电脑端：安装工具

```powershell
# ADB（Android 调试工具）
winget install --id Google.PlatformTools -e

# TigerVNC（VNC 客户端，开源无广告）
winget install --id TigerVNC.TigerVNC -e
```

装完**需要重启终端**，让 PATH 生效。

### ADB 的实际路径

winget 装的 ADB 在：

```
C:\Users\<用户名>\AppData\Local\Microsoft\WinGet\Packages\Google.PlatformTools_Microsoft.Winget.Source_8wekyb3d8bbwe\platform-tools\adb.exe
```

如果 `adb` 命令找不到，用完整路径，或把它加到 PATH。

> **提示**：`where.exe adb` 可以用来定位。注意 Bash 里要用 `where.exe` 而不是 `which`。

## 1.4 网络：Tailscale 组网

手机和电脑都装 [Tailscale](https://tailscale.com/)，登录**同一个账号**。

### 为什么需要它

| 方案 | 局限 |
|------|------|
| 局域网直连 | 手机和电脑必须在同一个 WiFi |
| 端口映射 | 需要公网 IP，家庭宽带通常没有 |
| **Tailscale** | ✅ 自动打洞 P2P，跨网络可用 |

它会给每台设备分配固定的 `100.x.x.x` 地址，自动尝试 P2P 直连，打不通才走中继（DERP）。

**实际效果**：你在外面用手机流量，也能连家里的电脑；在家也能连外面手机。

### 验证

```bash
tailscale status
```

输出中应能看到手机设备，状态为 `active` 或 `idle`：

```
<PHONE_IP>   nubia-m153    user@  android   active; direct 192.168.3.155:38829
<PC_IP>    fengair       user@  windows   -
```

### 排查

| 现象 | 原因 | 解法 |
|------|------|------|
| 手机显示 `offline` | 手机没网或 Tailscale 没运行 | 在手机上打开 Tailscale |
| 显示 `relay "xxx"` | P2P 打洞失败，走中继 | 能用但延迟高，可尝试换网络 |
| 完全看不到设备 | 登录的账号不同 | 确认两台设备登录同一账号 |

> **重要**：Tailscale IP 是**固定不变**的，所以后续所有配置可以直接写死。这让 SSH config、VNC 地址都不需要动态更新。

## 1.5 设备信息记录

开始前建议记录下这些值，后续配置会用到：

```bash
# 在手机 Termux 里执行
whoami          # Termux 用户名，如 <TERMUX_USER>
uname -m        # 架构，应为 aarch64
getprop ro.build.version.release   # Android 版本

# 在电脑上执行
tailscale status | grep -i <手机名>   # 手机 Tailscale IP
adb devices                          # ADB 序列号（需插 USB）
```
