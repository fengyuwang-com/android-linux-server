# 08 - 故障排查

按症状索引。所有问题都是实际踩过的。

## SSH 相关

### Connection refused

**含义**：网络通，但 sshd 没在监听。

```bash
ping <PHONE_IP>                                          # 通不通
timeout 5 bash -c 'echo > /dev/tcp/<PHONE_IP>/8022'      # 端口通不通
```

ping 通但端口不通 → 手机在，sshd 挂了。

**解法**：
1. 用 ADB 救援（见 [06-ADB指南.md](06-ADB指南.md) 的救援流程）
2. 或让手机端手动开 Termux 敲 `sshd`

### Connection timed out

**含义**：网络层不通。

排查顺序：
1. 手机是否在线（`tailscale status | grep nubia`）
2. 手机是否息屏休眠太久（保活失效）
3. Tailscale 是否在运行

### 刚装完包 SSH 就断了

**原因**：`pkg upgrade` 替换 sshd 二进制时打死了会话。

**解法**：装 dpkg 钩子（见 [07-自愈机制.md](07-自愈机制.md) 第 5 层），或每次装包前确保 USB 在手边。

### Permission denied (publickey)

```bash
# 在手机上检查权限
ls -la ~/.ssh/
# 应为：drwx------  .ssh
#       -rw-------  authorized_keys
```

常见原因：
- 公钥内容有换行断裂（必须**一行**）
- 文件权限不对
- 写到了错误的用户目录

### 连接频繁断开

配 `ServerAliveInterval`：

```
Host nubia
    ServerAliveInterval 30
    ServerAliveCountMax 3
```

## 软件源 / 安装相关

### pkg install 卡住不动

**症状**：超过 2 分钟没有任何下载百分比，手机无流量。

**原因**：默认镜像 `mirror.accum.se`（瑞典）国内不可达。

**迷惑点**：`pkg update` 显示 "Hit" 是**假象**——那是读本地缓存。

**解法**：换清华源（见 [03-工具链与镜像源.md](03-工具链与镜像源.md)）。

### CANNOT LINK EXECUTABLE: cannot locate symbol ...from_chars...

**原因**：`libc++` 版本过旧。

**诊断**：
```bash
dpkg -l | grep libc++
apt-cache policy libc++
```

**解法**：
```bash
pkg install -y "libc++=<Candidate版本>"
```

### dependency problems prevent configuration of ...

**原因**：通常是上游某个包配置失败（如 ffmpeg）导致依赖它的包全部卡住。

**解法**：先修那个上游包（多数是 libc++ 版本问题），它会连带完成。

### 在 Termux 里写 /tmp 报 Permission denied

Termux 里 `/tmp` 不可写。

**解法**：用 `$PREFIX/tmp` 或家目录。

```bash
echo hi > $PREFIX/tmp/test   # ✅
echo hi > ~/test             # ✅
```

### which: command not found

Termux 默认不装 `which`。

**解法**：
```bash
command -v python
```

## VNC 相关

### VNC 连不上

```bash
ssh nubia 'pgrep -af Xvnc'          # 进程在不在
ssh nubia '~/start-vnc.sh'          # 不在就重启
ssh nubia 'tail -30 ~/.vnc/*:1.log' # 看日志
```

### Bad obfuscated password length

密码文件损坏。从手机重新复制：

```bash
ssh nubia 'base64 -w0 ~/.vnc/passwd' | base64 -d > ~/.vnc/passwd
```

### Authentication failed

密码文件不匹配。同样重新复制。

> **不要自己生成密码文件**——见 [04-图形桌面.md](04-图形桌面.md) 4.3 节的说明。

### 黑屏 / 灰底

`~/.vnc/xstartup` 没配好或没执行权限。

```bash
ssh nubia 'ls -la ~/.vnc/xstartup'   # 需要有 x 权限
ssh nubia 'cat ~/.vnc/xstartup'
```

### 只有手机本机能连，电脑连不上

`-localhost no` 没生效。

```bash
# 确认启动命令里有这个参数
ssh nubia 'grep localhost ~/start-vnc.sh'
```

## 息屏 / 保活相关

### 息屏 20 秒就断

保活没生效。

```bash
# 1. 检查播放进程
ssh nubia 'pgrep -af termux-media-player'

# 2. 检查音频文件在不在
ssh nubia 'ls -la ~/.termux/quiet_1min.amr'

# 3. 检查 Termux:API 装了没
adb shell pm list packages | grep termux.api
```

补装步骤见 [05-息屏保活.md](05-息屏保活.md)。

### 保活进程反复重启

```bash
tail -20 ~/.termux/watchdog.log
```

频繁 "keepalive restarted" → AMR 文件可能损坏，重新生成。

### 装不了 Termux:API 的权限

`pm grant` 报错说明权限名不对（不同 Android 版本权限名不同）。

**解法**：用 `pm list permissions` 查实际名称，或在手机设置里手动给。

## ADB 相关

### adb: command not found

winget 装的 ADB 不在 PATH 里。

**解法**：用完整路径，或 `where.exe adb` 定位后加 PATH。

### Windows 报"未知 USB 设备(设备描述符请求失败)"

**不是驱动问题**，是手机 USB 模式不对。

**解法**：拔插数据线，在手机下拉通知栏选 **传输文件 (MTP)**。

### adb devices 显示 unauthorized

手机上没点"允许 USB 调试"。

**解法**：在手机上确认弹窗，勾选"始终允许"。

### adb devices 显示 offline

```bash
adb reconnect
# 或
adb kill-server && adb start-server && adb devices
```

### run-as: package not debuggable

**预期行为**。正式版 Termux 不是 debuggable 应用，`run-as` 不可用。

**这阻塞了"从 ADB 读 Termux 内部文件"的路径**——只能通过 SSH。

### 无法用 ADB 给 Termux 发命令

```bash
# 报错：Requires permission not exported from uid 10246
adb shell am startservice -n com.termux/com.termux.app.TermuxService ...
```

**原因**：Termux 的 Service 明确声明不导出（安全设计）。

**唯一可行路径**：`force-stop` + 重启 Termux，靠 `.bashrc` 自启（见 [06-ADB指南.md](06-ADB指南.md)）。

## 进程检测相关

### pgrep -x 报"未运行"但实际在运行

**原因**：进程名带参数。

```bash
pgrep -x sshd      # ❌ 匹配不到 "sshd -D -e"
pgrep -f "sshd -D" # ✅ 正确
```

**统一用 `-f`。**

### pgrep 匹配到了自己的命令行

```bash
ps -A | grep termux    # 会匹配到 grep 自身
```

**解法**：用 `pgrep -f`（不匹配自己），或在 grep 上排除：
```bash
grep -v grep
```

## 系统 / 环境相关

### 装不了 Microsoft Edge / Chrome

**架构限制**，非配置问题。原因见 [04-图形桌面.md](04-图形桌面.md) 4.7 节。

**替代**：`pkg install firefox` 或 `pkg install chromium`（Termux 官方重编译版）。

### 没有 /etc/os-release

Termux 是应用沙箱，没有标准 Linux 的这个文件。

**影响**：某些工具靠它判断发行版，读不到会行为异常。

**解法**：在 `$PREFIX/etc/os-release` 造一个（如果需要）。

### 中文文件名乱码

Termux 默认 locale 可能不是 UTF-8。

```bash
export LANG=zh_CN.UTF-8
export LC_ALL=zh_CN.UTF-8
```

写进 `.bashrc` 持久化。

## 快速诊断脚本

把这一段存成 `~/health.sh`，一键排查：

```bash
#!/data/data/com.termux/files/usr/bin/bash
echo "=== 系统 ==="
date; uptime; echo

echo "=== 进程 ==="
for p in runsvdir "runsv sshd" "sshd -D" crond "Xvnc :1" "termux-media-player"; do
  printf "%-24s: " "$p"
  pgrep -f "$p" >/dev/null && echo OK || echo FAIL
done
echo

echo "=== 端口 ==="
for port in 8022 5901; do
  printf "%-6s: " "$port"
  (echo > /dev/tcp/127.0.0.1/$port) 2>/dev/null && echo LISTENING || echo closed
done
echo

echo "=== 磁盘 ==="
df -h $HOME | tail -1
echo

echo "=== 看门狗日志（最近5条）==="
tail -5 ~/.termux/watchdog.log 2>/dev/null || echo "(无日志)"
```

```bash
chmod +x ~/health.sh && ~/health.sh
```
